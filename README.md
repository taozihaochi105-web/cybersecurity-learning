# Cybersecurity Learning

This repository documents my hands-on learning journey in web security and cybersecurity.

My academic background is not in computer science, so I use this repository to record how I build my understanding step by step — from basic web concepts to security testing.

Rather than collecting payloads, I focus on:

- understanding how web applications work;
- analyzing HTTP requests and application state;
- forming and testing security hypotheses;
- reproducing vulnerabilities in authorized lab environments;
- understanding root causes and mitigations.

## Learning Path

- HTTP and Web Basics
- Authentication Security
- XSS
- CSRF
- SQL Injection
- SSRF
- Redis Security
- Source Code Analysis

## Labs

Current environments include:

- Pikachu
- DVWA
- local Docker / virtual machine labs

## Notes

All experiments in this repository are performed in authorized lab environments for educational purposes.
